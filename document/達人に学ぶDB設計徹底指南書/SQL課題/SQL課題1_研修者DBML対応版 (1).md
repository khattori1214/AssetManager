# SQL課題1：社内研修・資格管理システム

## 1. 課題概要

研修者が作成したDB設計課題1のDBMLをもとに、SQLの基礎を学習します。

本課題のテーブル名・カラム名は、今回提出された研修者のDBMLに合わせています。

使用するテーブル：

```text
departments
employees
trainings
employee_trainings
qualifications
employee_qualifications
```

対象DBMS：

```text
MySQL 8系
```


### 使用するカラム

以下はSQL課題で使用する主なカラムです。その他のカラムや制約は、研修者のDBMLを参照してください。

| テーブル | 主キー | 主なカラム |
| --- | --- | --- |
| departments | department_id | department_code, department_name |
| employees | employee_id | employee_code, employee_name, email, department_id |
| trainings | training_id | training_code, training_name, training_category, training_date, instructor_name |
| employee_trainings | employee_trainings_id | employee_id, training_id, attendance_status, attendance_result, score |
| qualifications | qualification_id | qualification_name |
| employee_qualifications | employee_qualification_id | employee_id, qualification_id, acquired_date, expiration_date |

- 「社員番号」は`employees.employee_code`です。
- 「受講状況」は`employee_trainings.attendance_status`、「受講結果」は`attendance_result`、「受講点数」は`score`です。
- 「取得日」は`employee_qualifications.acquired_date`、「有効期限」は`expiration_date`です。
- 主キー名は各テーブルで異なります。DBMLに存在しない`id`カラムを前提にしないでください。

### 件数の数え方

本課題では、以下の意味で件数を数えます。

- **研修登録件数**：`employee_trainings`に登録されている件数。申込済・受講済・欠席のすべてを含みます。
- **研修ごとの登録者数**：その研修に登録されている社員数。申込済・受講済・欠席のすべてを含みます。
- **受講済研修数**：受講状況が`受講済`の研修登録件数。
- **保有資格数**：`employee_qualifications`に登録されている資格の件数。本課題では有効期限による除外は行いません。

今回のDBMLでは、社員と研修の組み合わせ、および社員と資格の組み合わせにそれぞれUNIQUE制約があります。

## 検証用fixture

本課題では、研修者のDBMLに合わせて指導者が用意した**SQL演習用fixture（テーブル定義と初期データ）**を適用してから開始してください。

DB設計課題1の元データを基本とし、同じ社員・部署・研修・資格の重複情報を整理して、6テーブルへ登録したデータを使用します。欠席・申込済の受講結果や点数、有効期限がない資格の有効期限は、空文字や0ではなく`NULL`として登録してください。

fixtureには少なくとも、

```text
研修登録0件の社員
資格保有0件の社員
登録者0人の研修
```

が含まれているものとします。

元データの社員には全員研修登録があるため、研修登録0件の社員は演習用に追加してください。資格保有0件の社員は元データにも存在するため、そのケースを維持してください。

これにより、`INNER JOIN`と`LEFT JOIN`の違いや、関連データが0件の場合の挙動を実際に確認します。

fixtureはこの課題文には含まれていません。課題開始前に、指導者が今回のテーブル名・カラム名に対応したものを別途用意してください。
